## Innovativer Einkaufsassistent: Entwicklung einer Einkaufslisten-Funktion für die Schobbow-Experience-App

Die Schobbow Experience App ist eine Desktop-Anwendung zur Erstellung und Verwaltung von Einkaufslisten.  
Sie unterstützt Nutzer:innen dabei, ihren Einkauf besser zu planen, den Überblick zu behalten und effizienter einzukaufen.  
Die Anwendung ist einfach und intuitiv bedienbar und eignet sich auch für Personen mit wenig technischer Erfahrung.

---

## Installation

1. Lade die bereitgestellte `.jar`-Datei herunter  
2. Stelle sicher, dass Java (JRE) auf deinem Computer installiert ist  
3. Starte die Anwendung per Doppelklick auf die `.jar`-Datei  
4. Eventuelle Sicherheitswarnungen müssen bestätigt werden  

Die Anwendung ist sofort einsatzbereit. Eine zusätzliche Installation ist nicht erforderlich.

---

## Funktionen

Die wichtigsten Funktionen der Anwendung:

- Produkte hinzufügen  
  Eingabe über ein Textfeld mit automatischer Vorschlagsfunktion  

- Produkte löschen  
  Entfernen über ein Kontextmenü  

- Mengen anpassen  
  Individuelle Mengen für jedes Produkt festlegen  

- Produkte abhaken  
  Gekaufte Artikel können markiert werden  

- Automatische Sortierung  
  Produkte werden nach Abteilungen sortiert, um den Einkaufsweg zu optimieren  

- Auswahl Markt  
  Über Ein Untermenü kann der Filial-Standort ausgewählt werden

- Anzeige Aufbau  
  Über einen Button kann ein Bild vom Markt-Aufbau angezeigt werden


---

## Zweck der Anwendung

Die App wurde entwickelt, um den Einkaufsprozess übersichtlicher, strukturierter und effizienter zu gestalten.  
Alle Daten werden lokal gespeichert, sodass keine Internetverbindung notwendig ist und der Datenschutz gewährleistet bleibt.
